# NNNN. Title in the imperative, such as "Put model access behind a port"

- Status: Proposed | Accepted | Superseded by [NNNN](NNNN-title.md)
- Date: YYYY-MM-DD
- Deciders: who made the decision, by role

## Context

The situation and the forces in it: what is true now, what hurts, and
what constraints any answer must respect. Facts, with numbers where you
have them.

## Options

Each option considered, in a sentence or two, with what it would cost.
Include the option of doing nothing.

## Decision

What we will do, stated so that someone can tell later whether the code
follows it.

## Because

Why this option beats the others for this context.

## Consequences

What becomes easier and what becomes harder, including the costs we
accept on purpose.

## Revisit when

The signal that would make this decision worth reopening.
