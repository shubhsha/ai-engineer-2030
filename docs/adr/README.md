# Architecture decision records

Each file records one significant decision: its context, the options,
the decision, the reasons, the consequences and the signal to revisit
it. An accepted record is never rewritten; a later record supersedes it.
ADR 0001 explains why, and `template.md` is the starting point for a new
one (or run `/new-adr Title` in Claude Code).
